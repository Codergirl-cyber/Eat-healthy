# EAT HEALTHY

A modern fruit discovery web app that helps users explore fruits based on their needs and seasonal preferences. Instead of endlessly searching for what fruit fits a specific goal, users can quickly discover relevant fruits and useful information through a clean and simple interface.

## Features

* Fast and interactive browsing experience

## Why I Built This

I built this project to practice frontend development while creating something useful. People often know they want to eat healthier but are unsure which fruits fit their needs or what fruits are best during a particular season. I wanted to create a simple experience that makes discovering fruits easier.

## Challenges

* Organizing fruit information in a user-friendly way
* Building a smooth and responsive UI
* Structuring components efficiently
* Making the experience simple without overwhelming users

## What I Learned

* Building reusable React components
* Improving responsive UI design
* Managing and displaying dynamic content
* Creating a cleaner user experience
